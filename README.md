# AsciiMorph

A Windows Forms application for transforming ASCII symbols with custom patterns.

## Description
AsciiMorph is a C# Windows Forms application that allows users to input a sequence of ASCII symbols and apply a transformation pattern to generate a new sequence of symbols. Designed for creative ASCII art generation or encoding experiments, it supports dynamic input fields (up to 25 symbols), validates input, and provides debug output for transformation steps. Features include intuitive navigation with Enter and Backspace keys, automatic focus switching, and a clear interface for generating and resetting outputs. Ideal for users exploring ASCII-based transformations or educational purposes in programming and character encoding.

## Features
- Dynamic input fields for up to 25 ASCII symbols
- Pattern-based transformation of ASCII characters
- Debug output showing transformation steps
- Navigation with Enter and Backspace keys for efficient input
- Automatic focus switching between input fields
- Clear button to reset all inputs and outputs
- Input validation for single-character symbo
